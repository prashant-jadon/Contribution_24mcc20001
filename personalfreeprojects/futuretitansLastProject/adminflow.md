
# 🛠️ **ADMIN FLOW DOCUMENT – Future Titans Innovation Challenge Platform**

## **1. Overview**

The **Admin Portal** is the control center for managing:

* Students
* Modules & learning content
* The AI co-founder system
* SURGE Framework scoring
* Competition submission forms
* Payments, analytics, leaderboards, and communication

Administrators can create learning journeys, monitor student progress, manage AI behavior, evaluate submissions, and generate reports.

---

# 🔐 **2. Admin Login & Authentication**

Admin visits the portal and logs in using:

* Email
* Password
* Two-factor authentication (optional)

Roles include:

* **Super Admin**
* **Content Manager**
* **AI Manager**
* **Judge/Reviewer**
* **Support Staff**

Each role has different permissions.

---

# 📊 **3. Admin Dashboard (Home)**

Upon logging in, admin sees:

### **Top KPIs**

* Total Registered Students
* Total Paid Students
* Total Modules
* Completion Rate %
* Average SSI Score
* Submissions Received
* Pending Reviews
* AI Usage Statistics

### **Quick Actions**

* Add Module
* Add Chapter
* Create Competition Form
* Update AI Prompt
* View Submissions

### **Live Activity Feed**

Shows:

* New student registrations
* Module completions
* New form submissions
* High/low SSI scores flagged

---

# 📚 **4. Module Management System**

## **4.1 Create Module**

Admin can create course-style learning modules:

**Fields:**

* Module Title
* Module Description
* Difficulty Level
* Cover Image
* Estimated Completion Time
* AI Interaction On/Off
* SURGE evaluation weight (optional)

---

## **4.2 Add Chapters to Module**

A module can have unlimited chapters.

Admin can add:

### **Content Types:**

* **Video** (upload or link)
* **Text lessons**
* **Subtitles for AI training**
* **PDF / Documents**
* **Audio lessons**
* **Practice questions**
* **AI Interaction Block (conversation triggers)**

### **AI Interaction Settings**

Each chapter can have AI enabled with:

* Custom prompt
* Context injection:

  * Chapter text
  * Subtitles
  * Relevant PDFs (converted to text)
* SURGE dimension focus
* Max messages per conversation

---

## **4.3 Reorder / Delete Chapters**

Drag & drop chapter ordering.
Enable/Disable chapter visibility.

---

# 🤖 **5. AI Bot Management**

Admin controls the AI that interacts with students.

## **5.1 AI Prompt Update**

Admin can edit master AI prompt:

* SURGE Framework instructions
* Co-founder personality
* Scoring system
* How to challenge limiting beliefs
* Tone of conversation (mentor, coach, friendly)

## **5.2 Context Settings**

Admin chooses what context AI has access to:

* Student previous messages
* Module text
* PDF summaries
* User profile data
* SSI history

## **5.3 Safety & Compliance Settings**

* Restricted words
* Avoid giving business-sensitive advice
* Avoid mental health + harmful content
* Ethical AI response filter

---

# 🧠 **6. SURGE Framework SSI Scoring**

Admin can:

### **View each student's SSI breakdown:**

* Self Awareness
* Understanding Opportunities
* Resilience
* Growth Execution
* Entrepreneurial Leadership

### **Customizable Scoring Rules:**

Admin can change:

* Weightage per SURGE dimension
* Minimum word count per AI evaluation
* Penalties for vague answers
* Limits for low-quality responses

### **Flagging System**

Low resilience or low clarity are auto-flagged for review.

---

# 🧑‍🎓 **7. Student Management**

Admin sees a table of all students.

### **Filter/Sort By:**

* Name
* Email
* School / Institution
* City / Country
* Payment status
* Module progress
* SSI Score
* High/Low SURGE dimension
* Idea Submission Status
* PDF submitted/not
* Video submitted/not

### **Actions:**

* View full student profile
* View full AI conversation history
* View module progress
* Reset module progress
* Adjust SSI score manually (optional)
* Tag students (e.g., “high potential”, “needs support”)
* Send message or announcement

### **Student Grouping**

Admin can create custom groups:

* Top scorers
* Students below 40% SSI
* Students from specific institutions
* Students in a certain country
* Students with complete/incomplete submissions

---

# 📝 **8. Competition Form Builder**

Admin creates the **long final form** students must complete.

## **8.1 Add Questions**

For each question, admin sets:

* Question Title
* Description
* Word Limit (for text responses)
* Type:

  * Text (short/long)
  * Number
  * Dropdown
  * Multiple Choice
  * PDF Upload
  * Image Upload
  * Video Upload
  * File (any type)

### **Validation Options:**

* Required / Optional
* Min/Max file size
* Allowed formats (PDF only, JPG, MP4, etc.)
* Word count enforcement

---

## **8.2 Arrange Questions**

Drag to reorder.

---

## **8.3 Preview Form**

Admin can preview the exact form students will see.

---

## **8.4 Publish/Update Form**

Changes are saved in real time.
Previous answers remain saved if form updated.

---
