                         HOW TO RUN THE SYSTEM
═══════════════════════════════════════════════════════════════════════════════

PREREQUISITES
   ✓ Node.js 18+
   ✓ npm 9+
   ✓ MongoDB 5+ (local or Atlas)
   ✓ Razorpay account (optional for dev)
   ✓ Gemini API key (optional for dev)

INSTALLATION
   1. cd backend && npm install && cd ..
   2. cd frontend && npm install && cd ..
   3. Create .env file with credentials
   4. Start MongoDB (if local): mongod

RUNNING LOCALLY
   Terminal 1: cd backend && npm run dev
   Terminal 2: cd frontend && npm run dev

ACCESSING
   Frontend:  http://localhost:3000
   Backend:   http://localhost:5006
   API Docs:  http://localhost:5006/api-docs
