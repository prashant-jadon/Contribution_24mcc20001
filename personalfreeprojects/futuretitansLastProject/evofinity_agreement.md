# Software Development & Maintenance Agreement

**Date:** March 23, 2026

This Software Development and Maintenance Agreement (the "Agreement") is entered into by and between:

**Developer:** Prashant Jadon (hereinafter referred to as "Developer")  
**Client:** Evofinity (hereinafter referred to as "Client")  

## 1. Project Overview
The Developer agrees to design, develop, and deliver a custom application for the Client, and provide ongoing monthly maintenance services as outlined in this Agreement.

## 2. Development Deliverables
As part of the initial application development, the Client will receive the following from the development side:

- **Custom Application Development:** Full development of the application tailored to the Client's specific feature requirements and business logic.
- **UI/UX Implementation:** Clean, responsive, and intuitive user interface implementation based on project requirements.
- **Backend & Database Setup:** Secure backend architecture, server setup, and database integration to support the application's core functionality.
- **Quality Assurance & Testing:** Comprehensive end-to-end testing to ensure the app is stable, bug-free, and performs optimally before the official launch.
- **Deployment & Launch:** End-to-end assistance with deploying and launching the application on the relevant platforms (e.g., App Store, Google Play Store, or Web Hosting).
- **Source Code Ownership:** Complete handover of the application's source code and related intellectual property upon final payment of the development fee.
- **Basic Project Documentation:** A general guide or structural documentation outlining the app's architecture, APIs, and basic usage setup.

## 3. Maintenance Services
The ongoing monthly maintenance services include the following:

- **Regular Backups:** Ensuring all application data, user data, and databases are securely backed up on a regular schedule.
- **Bug Fixes:** Prompt resolution of any minor bugs, glitches, or unexpected behaviors that arise post-launch.
- **Performance Monitoring:** Continuous monitoring of server uptime, API response times, and overall app performance.
- **OS & Platform Compatibility Updates:** Keeping the application updated to remain compatible with the latest operating system (iOS/Android/Web browsers) updates.
- **Security Patches:** Applying necessary security updates to protect user data and prevent vulnerabilities.
- *(Note: Major new feature additions, full UI redesigns, or significant architectural changes are not covered under regular maintenance and will be estimated and billed separately.)*

## 4. Payment Terms
In consideration of the services provided, the Client agrees to compensate the Developer as follows:

- **Total App Development Fee:** Rs. 120,000 (One-time payment)
- **Ongoing Maintenance Fee:** Rs. 30,000 per month

### Suggested Payment Schedule:
- **Development Phase:** 50% upfront (Rs. 60,000) to commence work, 50% (Rs. 60,000) upon project completion and successful deployment. *(Adjust as necessary)*
- **Maintenance Phase:** The monthly maintenance fee of Rs. 30,000 shall be billed at the beginning of each billing cycle starting from the month following the app's official launch.
